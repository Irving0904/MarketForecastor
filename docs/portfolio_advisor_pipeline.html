Request lifecycle

How one message moves through Portfolio Advisor

Every advisor message forks into exactly one of two pipelines the moment it arrives, and both are re-joined at a single point before anything reaches the screen. The fork is looks_like_portfolio(); the re-join is the guardrail layer — the one piece of this system every other design choice here exists to protect.

Why the fork exists: a portfolio submission is a batch data-processing job — fetch, aggregate, summarize — with no ambiguity about what to do with it. A follow-up question is not: Router Agent still has to decide, per question, whether it's a one-fact lookup or something that needs several angles weighed against each other. Collapsing these into one pipeline would mean paying ToT's five-model-call cost for “what's AAPL's yield”, or answering “should I rebalance” with a single tool call and no deliberation.

What each stage is actually built from

Data Aggregator → Portfolio Analyst

A two-agent CrewAI crew. The Aggregator's only tool is a Yahoo Finance wrapper; the Analyst never touches a network call — it only reasons over the JSON it's handed.

Rollup alerts + cross-check

Diffs this fetch against the client's own last-saved snapshot for rating/price moves, and diffs Yahoo's earnings/news against Alpha Vantage. Silent when there's nothing to flag — never fabricates a change.

Router Agent

One LangChain classification call. Defaults toward tot on an ambiguous label, so an open-ended question gets deliberation instead of silently falling to the cheap path.

ReAct Agent

A LangChain tool-calling loop with three tools: holding data, SEC filing search, and this client's own conversation history — the only agent in the system that calls a search index.

ToT Crew

Three CrewAI analysts argue from different lenses, a critic scores them, a synthesizer picks a side. No tools of its own — it cites news already fetched for the profile, never a live lookup.

Guardrails & Evaluators

DataAccessGuard and a startup read-only audit run once, at construction; ContentPolicyGuard and ConfidenceRouter run on every reply, annotating rather than rewriting it.
